# PhotoPlayer

## 作品简介

**作品名称：基于FPGA的图片播放器设计**

本项目使用安路 EG4S20BG256 FPGA，实现 TF 卡图片读取、SDRAM 帧缓存及 HDMI 图像与音频输出，并加入图片转场、缩放、滚动字幕、亮度调节与音频波形叠加功能。

## 已实现功能

- 图片播放：从 TF 卡读取 BMP 图片，KEY2 手动切图，KEY4 自动轮播。
- 转场特效：KEY3 开启或关闭淡入淡出。
- 图片缩放：支持不同分辨率的24位非压缩 BMP 图片，缩放适配640×480输出画面。
- 字幕叠加：显示滚动标语“读万卷书，行万里路”。
- 亮度调节：使用 SW1/SW2 调节亮度，并在画面中显示亮度信息。
- 音频输出：通过 HDMI 输出内部测试音。
- 音频可视化：叠加单条左声道 PCM 波形，由 SW3 控制显示或隐藏。
- 掉电保存：程序写入 Flash 后，重新上电可自动运行。

## 获取代码

本仓库以 RAR 压缩包形式提供完整工程，请在仓库文件列表中下载代码包后解压。请勿直接从压缩包内打开 TD 工程。

解压后，先阅读 `PhotoPlayer_Source/00_打开工程与目录说明.md`。

## 开发环境与运行

- FPGA器件：安路 EG4S20BG256。
- 开发软件：Anlogic Tang Dynasty（TD）6.2.1。
- 外设：TF卡、HDMI显示器；验证声音需使用支持HDMI音频的显示设备。
- 工程入口：`PhotoPlayer_Source/01_TD_Project/src/td_project/PhotoPlayer.al`。
- 顶层模块：`top`。
- 已验证下载文件：`PhotoPlayer_Source/04_Bitstream/PhotoPlayer.bit`。

基本步骤：

1. 将完整代码包解压到本地目录，建议使用不含中文和空格的路径。
2. 在 TD 中打开上述 `PhotoPlayer.al` 工程。
3. 检查工程器件及源文件是否正确加载，运行综合、布局布线和位流生成。
4. 将生成的 bit 文件下载到板卡，或使用随包提供的已验证 bit 文件进行功能对照。
5. 按使用说明准备 TF 卡图片，连接 HDMI 显示器并启动板卡。
6. 如需断电后自动运行，按板卡烧录流程将程序写入 Flash；仅下载至 FPGA 不代表已完成 Flash 固化。

按键、开关及素材格式的详细说明，以解压后随附文档为准。

## 验证情况与限制

板卡实测已通过手动切图、自动轮播、淡入淡出、亮度调节、不同分辨率图片缩放、滚动字幕、单波形开关及 HDMI 声音输出测试，并验证 Flash 固化后断电重启自动运行。尚未进行长期运行时长或切图次数的统计测试。

当前音源为内部八音阶测试音，波形属于时域可视化，未实现 FFT 频谱分析或外部音乐文件解码。

TF 卡读取存在文件连续存储、前64MiB扫描范围及最多4张BMP图片等约束，具体准备方式请参照随附使用说明。

工程仍存在静态时序违例；已通过的功能测试和模块仿真不代表完整时序签核。
